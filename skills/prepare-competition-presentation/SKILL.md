# Prepare competition presentation and Q&A

Use the official format/time limits, idea/evidence handoffs, implemented demo and latest review issues. Preserve claim IDs and implementation labels across all presentation artifacts.

- For deck/IR structure, read [judge-first-deck](references/judge-first-deck.md).
- For 질의응답, hostile questions or full presentation preparation, read [hostile-qa](references/hostile-qa.md). After independent review, refresh only answers affected by new findings.
- For a speaking-script request, align narration to slide questions, demo transitions and the official time budget. Rehearse aloud and record actual duration; estimates are labeled estimates.

A full presentation returns judge-question→slide→evidence→visual→takeaway mapping, slide outline, timed script and Q&A cards. Q&A-only returns cards and evidence gaps. Cards preserve 질문 의도, 위험 답변, 20초 답변, 근거, 후속공격, 10초 재반박. Provide actual PPTX/PDF only with appropriate available creation/rendering tools and inspect the exported result; otherwise deliver an honest outline.

Route defects to review and proposed substantive revisions through guarded refinement. A persuasive answer cannot substitute for missing evidence.
