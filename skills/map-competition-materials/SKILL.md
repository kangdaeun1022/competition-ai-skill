# Map competition materials

Use this optional skill when relationships across many files are unclear. Agree the bounded corpus; preserve source files and record inaccessible items.

Assign stable IDs to files, claims, evidence passages, features, demo steps and rubric items. For each edge record source and target IDs, relationship (supports/contradicts/implements/tests/required-by), exact location, and extracted versus inferred status. Track source versions so a changed source invalidates affected edges.

Return a compact edge table or graph, orphan claims, conflicting statements, missing implementation links and the smallest set of documents requiring human attention. Cite original locations, not only summaries. A graph does not increase the evidentiary strength of its inputs. No external graph service is required; upload private materials only with authorization. Completion means the decisive claims have traceable links or explicit gaps.
